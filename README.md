# James Cubito — Engineering Portfolio

Professional engineering portfolio website for James Cubito, Graduate Registered Electrical Engineer from Pamantasan ng Lungsod ng Maynila. Tailored for the power systems, controls, energy, and electrical infrastructure sectors.

## Built With
- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS, Custom CSS Variables (Light & Dark Theme)
- **Icons:** Lucide React
- **Deployment:** GitHub Pages (Automated CI/CD via GitHub Actions)
