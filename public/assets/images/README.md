Place all image assets here. These are referenced in `src/data/constants.ts` using the path prefix `assets/images/`.

| File | Used For |
|---|---|
| `portrait.jpg` | Hero section portrait photo |
| `acen.png` | ACEN company logo (Experience) |
| `irah.png` | IRAH Solutions logo (Experience) |
| `plm.png` | PLM school logo (Education) |
| `dlsu.png` | DLSU school logo (Education) |
| `prc.png` | PRC logo (Certifications) |
| `tesda.png` | TESDA logo (Certifications) |
| `mf_treinamentos.png` | MF Treinamentos logo (Certifications) |
| `dost.png` | DOST-SEI logo (Certifications) |
| `viber_qr.png` | Viber QR code (Contact modal) |

## Notes
- Portrait image should be square or close to square for best display.
- All logos should be PNG with transparent or white backgrounds.
- Copy files from the original `jrfc-ee-main/public/assets/` folder.
